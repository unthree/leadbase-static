# Morning Routine Kit

Static, self-contained tools for running an optimized morning routine
built around three goals: more content, reliable email, more revenue.

## What's here

- **`routine-card.html`** — the digital routine card. Open it on any
  device, save it to your phone's home screen, or print it. No
  dependencies, works offline, adapts to light/dark mode.
- **`tracker.html`** — a small habit-tracker app. Check off each step
  daily; it keeps a 7-day view and a weekly scoreboard (videos filmed,
  inbox-zero mornings, revenue actions). Data is stored in the browser's
  localStorage — no account, no backend.
- **`agent-handoff/`** — a complete, vendor-neutral spec for automating
  the daily 6:30 AM iMessage to the "M1 Hermes" chat from a Mac. Hand
  `HANDOFF.md` to any desktop agent or follow it manually. Includes the
  AppleScript sender, a launchd schedule, and the message template.

## The routine

1. Activate — water + bed, no phone
2. P90X workout
3. Film a video *(content goal — create before you consume)*
4. Email block, 20 min *(email goal — inbox zero, timer on)*
5. One revenue action *(revenue goal — one per day, compounding)*
6. Twitter — post first, 15 min timer
7. Read
8. Journal + plan tomorrow's video topic and revenue action

Weekly scoreboard: videos filmed · inbox-zero mornings · revenue actions.
If a number stalls, fix that slot — don't overhaul the routine.
